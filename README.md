# Playwright Automation

Projeto de automação de testes utilizando Playwright com Java e JUnit 5.

## Tecnologias

- Java 17
- Playwright
- JUnit 5
- Maven

## Aplicação utilizada

[WebDriverUniversity](https://www.webdriveruniversity.com/)

## Cenários automatizados

### Contact Us

- Envio do formulário com dados válidos
- Validação de e-mail inválido

## Execução

Para executar os testes:

```bash
mvn clean test
